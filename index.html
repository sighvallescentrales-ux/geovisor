Guía rápida

Cómo utilizar el visor

  1. Elige un mapa base en la barra superior.
  2. En cada hacienda, activa el mapa histórico, el límite territorial o ambos.
  3. Ajusta el porcentaje de opacidad para comparar el pasado con el territorio actual.
  4. Activa un límite de hacienda para acercarte automáticamente a su extensión.

Los límites representan una reconstrucción histórica y deben interpretarse de acuerdo con las fuentes y la metodología del proyecto.
